# 記事から参照する固定版

通常のビルドで生成する `dist/widget/` は最新版です。記事で同じ内容を長く表示し続けたい場合は、コード、データ、Worker、CSS をまとめた固定版を、このディレクトリに追加します。

```sh
npm run build
npm run freeze:widget
git add releases
```

固定版は、配布内容の SHA-256 を名前に使ったディレクトリに保存されます。コミットすると、以後のビルドでも GitHub Pages の `releases/<識別子>/` にコピーされます。記事から参照している固定版を修正する場合は、新しい識別子で公開してください。既存のディレクトリは、その内容を参照する記事のために保持します。

生成された `example.html` を開くと、単独での動作を確認できます。CodePen での利用手順は、[埋め込みの説明](../docs/embedding.md) を参照してください。
