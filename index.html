    01 / 原典と対象版

    NIST SP 800-63-4、SP 800-63A-4、SP 800-63B-4、SP 800-63C-4 の正式版（2025年）の HTML 版 Glossary のみを収録。取得日：2026年10月9日。略称一覧は収録せず、略称単独での検索・対応付けも対象外です。同じ見出しを1ノードに集約し、定義は出典別に保持します。

    • SP 800-63-4 (189 定義)
    • SP 800-63A-4 (89 定義)
    • SP 800-63B-4 (124 定義)
    • SP 800-63C-4 (94 定義)

    02 / 語句の対応付け

    大文字・小文字を区別せず、単語境界を保って見出しを照合します。括弧内の末尾略称を除き、単数・複数形を規則的に扱います。長い複合語を優先し、その内部の短い語は重複登録しません。ハイフンは保持し、同義語・略称・語幹による推測はしません。対象は4文書すべての見出しで、文書をまたぐ参照も含みます。

    原典の明示参照 原文の「See …」「Synonymous with …」または用語集への明示リンク。
    独自の語句対応 見出しとの語句一致に基づく対応。原典の斜体は記録しますが、それだけで明示参照とは扱いません。自己参照も残します。

    基準：heading-longest-boundary-v1。各出現位置と出典を保存し、根拠表現を原文で強調表示します。

    03 / 翻訳と確認履歴

    英語原文は NIST の資料です。日本語訳は Codex による本プロジェクト独自の訳で、NIST の公式訳ではありません。条件、限定、否定、例示を対照確認し、専門用語の表記を統一しています。独立した人間による査読は未実施です。

    原典 HTML の SHA-256、定義ごとの SHA-256、訳文の作成・確認情報を保存。原文の更新で既存の訳が無条件に引き継がれない仕組みです。原典の空白を正規化し、段落・箇条書きの全内容を保持しています。
