# 手法と実装

分類と配置は独立して選択できます。実装は `src/analysis/` にまとめ、Node の検証とブラウザーの計算で共有しています。画面の説明・論文・計算条件は `methods.ts` を正本とします。

## 分析の入力

全出典の参照を用語の方向付きペアに集約し、出典間の重複と自己参照を分析の重みから除きます。無向方式は方向も除きます。原文中の参照箇所や自己参照は閲覧用データに残します。表示フィルターは分類・全体配置の入力を変えません。

## 用語群の分類

| 方式 | 目的・実装 | 原論文 |
| --- | --- | --- |
| 無向モジュラリティ | 無向 Q の改善量が最大の群を結合する決定的な貪欲法 | [Clauset et al. (2004)](https://arxiv.org/abs/cond-mat/0408187) |
| 有向モジュラリティ | 入次数・出次数を使う有向 Q を貪欲結合で改善。スペクトル法は未実装 | [Leicht & Newman (2008)](https://arxiv.org/abs/0709.4500) |
| 強連結成分 | 方向付き参照で相互到達する用語の厳密な分割。密度の分類ではない | [Tarjan (1972)](https://doi.org/10.1137/0201010) |
| ラベル伝播 | 無向隣接用語の多数ラベルへ順次更新。次数順、同数なら現在のラベル、最大100回 | [Raghavan et al. (2007)](https://arxiv.org/abs/0709.2938) |
| Louvain | 無向 Q が増えるノード移動と群の多段集約。解像度1、訪問順と同点処理を固定 | [Blondel et al. (2008)](https://arxiv.org/abs/0803.0476) |
| 情報流 | 15%の一様テレポーテーションを記録した定常流の2段階 map equation を、群の貪欲結合で短くする | [Rosvall & Bergstrom (2008)](https://arxiv.org/abs/0707.0609) |

無向 Q・有向 Q・符号長 L は異なる評価基準です。無向方式どうしは同じ Q でも比較できますが、目的関数の大小だけで意味的な分類の良し悪しは決まりません。

情報流の定常確率は変化量の L1 ノルムが 1e-13 未満、または最大1000回で求めます。出辺のない用語からは全用語へ一様に移ります。公式 Infomap の探索処理、階層 Infomap、Leiden は実装していません。用語群は NIST の公式な分類ではありません。

## 配置

| 方式 | 実装 |
| --- | --- |
| 用語グループ別 | 選択中の分類の群を並べ、群内は次数順に螺旋状に配置。この方式だけ分類に依存。群間隔は領域外の余白だけに適用 |
| 強連結成分の階層 | 強連結成分をまとめた DAG の最長路で層を決め、用語は個別に表示。幅が広い層は折り返す |
| 層状（Sugiyama 系） | DFS の戻り辺を配置計算の中だけ反転し、最長路で層を割り当て、長辺に仮想ノードを置き、重心法で順序を更新 |
| 力学（Fruchterman–Reingold） | 全ノード間の反発と隣接ノード間の引力、線形冷却。既定はシード42・250回 |
| 距離ストレス | 無向最短路距離に比例する目標距離へ近づける重み付き stress majorization。既定はシード42・180回・距離単位90 |
| 放射状（BFS） | 弱連結成分ごとに次数最大の用語を中心にし、無向の参照距離ごとに同心円に置く |
| 円形（次数順） | 弱連結成分ごとに次数順で円周に置く比較用の配置 |

力学・距離ストレス・放射状・円形は弱連結成分ごとに配置し、成分を並べます。孤立ノードも残します。成分内の座標は必要に応じて一様拡大し、初期状態のノード中心間隔を確保します。

層状配置は [Gansner et al. (1993)](https://graphviz.org/documentation/TSE93.pdf) の工程を参考にした簡略化で、network simplex・座標最適化・スプライン計算は含みません。力学配置は [Fruchterman & Reingold (1991)](https://reingold.co/force-directed.pdf) を参照しています。距離ストレスは [Gansner, Koren & North (2005; GD 2004)](https://doi.org/10.1007/978-3-540-31843-9_25) の stress majorization を使います。目標距離を dᵢⱼ = unit × hopᵢⱼ、重みを wᵢⱼ = dᵢⱼ⁻² とし、S(X) = Σᵢ<ⱼ wᵢⱼ(‖xᵢ−xⱼ‖−dᵢⱼ)² を最小化します。重み付きラプラシアン V と B(X)（非対角 −wᵢⱼdᵢⱼ/‖xᵢ−xⱼ‖、対角は行和を0にする値）について V X′ = B(X)X を解きます。1頂点を原点に固定して特異性を除き、Cholesky 分解を再利用します。主要化によって S は非増加ですが、大域最適性は保証しません。反復上限、相対改善量 1e-10、または丸め誤差による増加で停止します。表示時の間隔確保のための拡大後は、この単調性や距離単位を保証しません。放射状と円形は独自の補助配置です。

参照方向を除いて計算する配置でも、画面の矢印は原文に基づく元の方向です。局所表示は選択用語を中央に置く補助配置で、選択中の全体配置を表しません。

## 比較と再計算

比較表は全用語・既定条件の初期配置について計算します。群別配置は選択中の分類を使います。絞り込み、指定条件での再計算、用語の手動移動は表の値に含みません。

- 直線の交差数：自己参照・方向・重複を除き、共通端点・接触・同一直線上の重なりを含めず数える。画面の曲線の交差数とは異なる。
- 正規化平均辺長：平均辺長を配置全体の長方形の対角線で割る。孤立用語も尺度に影響する。
- 辺長 CV：辺長の標準偏差を平均で割る。

計算条件は方式ごとに保持し、「再計算」で更新します。「配置を初期状態に戻す」は現在の表示の手動座標と現在の方式の設定をリセットします。計算結果と手動座標は分けて保持します。再計算と比較は Worker で実行し、遅れて完了した過去の要求で最新の表示を上書きしません。

## 検証

既知のクリーク、循環、DAG、孤立用語を使い、独立した式で無向・有向 Q、定常流の入出一致、エントロピーによる符号長、距離ストレスの減少、交差数を検証します。全42組の所属・座標と分類から独立した配置の一致も検証します。方式や設定の切り替えと、グラフ・原文根拠の保持はブラウザーでも確認します。
