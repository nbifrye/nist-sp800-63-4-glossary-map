# 手法と実装

分類方法と配置方法は、それぞれ選択できます。実装は `src/analysis/` にまとめ、Node.js の検証とブラウザーでの計算に共用しています。画面に表示する説明、論文、計算条件は `methods.ts` で管理します。

## 分析の入力

選択中の出典に合う参照を、参照元と参照先の用語の組み合わせにまとめます。分析の重みには、出典間で重複する参照と自己参照を含めません。無向グラフを使う方式では、方向も取り除きます。用語 ID と辺は、入力順が違っても同点の場合の選択が変わらないように正規化します。原文中の参照箇所と自己参照は、閲覧用のデータに残します。出典を変えると、分類と全体の配置を再計算します。

## 用語の分類

| 方式 | 目的・実装 | 原論文 |
| --- | --- | --- |
| 無向モジュラリティ | 無向 Q の増加量が最も大きい群どうしを順に結合する。同じ入力からは常に同じ結果を得る | [Clauset et al. (2004)](https://arxiv.org/abs/cond-mat/0408187) |
| 有向モジュラリティ | 入次数と出次数を使って有向 Q を求め、増加量が最も大きい群どうしを順に結合する。原論文のスペクトル法は実装していない | [Leicht & Newman (2008)](https://arxiv.org/abs/0709.4500) |
| 強連結成分 | 矢印に沿って互いに行き来できる用語を、同じ群にまとめる | [Tarjan (1972)](https://doi.org/10.1137/0201010) |
| ラベル伝播 | 方向を取り除いた隣接関係を使い、隣接用語で最も多いラベルに順次更新する。次数順に処理し、同数なら現在のラベルを保つ。最大100回繰り返す | [Raghavan et al. (2007)](https://arxiv.org/abs/0709.2938) |
| Louvain | 無向 Q が増えるように用語の所属を変え、群をまとめて処理を繰り返す。解像度は1とし、処理順と同点の場合の選択を固定する | [Blondel et al. (2008)](https://arxiv.org/abs/0803.0476) |
| スペクトル分類 | Newman のモジュラリティ行列の最大固有値に対応する固有ベクトルを使い、群を繰り返し二分する。ΔQ が正の分割を採用する | [Newman (2006)](https://arxiv.org/abs/physics/0605087) |
| 情報流 | 15%の一様テレポーテーションを含む定常流を使う。2段階の map equation の符号長が最も短くなる群どうしを順に結合する | [Rosvall & Bergstrom (2008)](https://arxiv.org/abs/0707.0609) |

無向 Q、有向 Q、符号長 L は、それぞれ異なる評価基準です。無向グラフを使う方式どうしは、共通の Q で比較できます。ただし、目的関数の値だけで、語の意味に照らした分類の良し悪しが決まるわけではありません。

情報流の定常確率は、変化量の L1 ノルムが 1e-13 未満になるまで、最大1000回の反復で求めます。出辺のない用語からは、全用語へ等しい確率で移ります。公式 Infomap の探索処理、階層 Infomap、Leiden は実装していません。得られる用語グループは、本プロジェクト独自の分類です。

## 配置

| 方式 | 実装 |
| --- | --- |
| 用語グループ別 | 選択中の分類に従って群を並べ、群内の用語を次数順にらせん状に配置する。分類に応じて座標も変わる。群間隔の設定は、各群の領域の外側にある余白に適用する |
| 強連結成分の階層 | 強連結成分を1つずつの点にまとめた DAG の最長経路で層を決める。各用語は個別に表示し、幅が広くなる層は折り返す |
| 層状（Sugiyama 系） | 深さ優先探索（DFS）の戻り辺を計算中だけ反転する。最長経路で層を割り当て、長い辺に仮想ノードを置き、重心法で並び順を調整する |
| 力学（Fruchterman–Reingold） | 全ノード間の反発力と、隣接ノード間の引力を使う。移動量の上限を一定の割合で減らす。既定の乱数シードは42、反復回数は250回とする |
| 距離ストレス | 重み付き stress majorization によって、用語間の距離を、無向グラフの最短経路に比例する目標距離に近づける。既定の乱数シードは42、反復回数は180回、距離単位は90とする |
| スペクトル配置 | 成分ごとに L = D − A の0以外の固有値を小さい順に2つ選び、対応する固有ベクトルを二次元の座標に使う。表示時には近接した点を離す |
| 放射状（BFS） | 弱連結成分ごとに次数が最大の用語を中心に置く。方向を取り除いた参照の最短経路の長さに応じて、同心円上に配置する |
| 円形（次数順） | 比較の基準として、弱連結成分ごとに用語を次数順に円周上へ並べる |

力学、距離ストレス、スペクトル、放射状、円形の各方式では、弱連結成分ごとに配置を求めてから、成分を並べます。孤立したノードも残します。必要に応じて成分内の座標を一様に拡大し、初期状態でノードの中心間に十分な間隔を設けます。

層状配置は [Gansner et al. (1993)](https://graphviz.org/documentation/TSE93.pdf) の工程を参考に、処理を簡略化したものです。network simplex、座標の最適化、スプラインの計算は実装していません。

力学配置は [Fruchterman & Reingold (1991)](https://reingold.co/force-directed.pdf) を参照しています。

距離ストレスは [Gansner, Koren & North (2005; GD 2004)](https://doi.org/10.1007/978-3-540-31843-9_25) の stress majorization を使います。

目標距離を dᵢⱼ = unit × hopᵢⱼ、重みを wᵢⱼ = dᵢⱼ⁻² とし、S(X) = Σᵢ<ⱼ wᵢⱼ(‖xᵢ−xⱼ‖−dᵢⱼ)² を最小化します。重み付きラプラシアン V と B(X)（非対角 −wᵢⱼdᵢⱼ/‖xᵢ−xⱼ‖、対角は行和を0にする値）について V X′ = B(X)X を解きます。1つの頂点を原点に固定して行列の特異性を除き、Cholesky 分解の結果を再利用します。

上界を最小化するため S は増加しませんが、大域的な最適解は保証しません。反復回数が上限に達した場合、改善量が 1e-10 × max(1, S) 以下になった場合、丸め誤差によって値が増加した場合に停止します。表示の間隔を確保するために座標を拡大した後は、この単調性や距離単位を保証しません。

放射状と円形は、本プロジェクト独自の補助的な配置方法です。

参照の方向を取り除いて配置を計算する場合も、画面の矢印は原文に基づく方向で表示します。周辺表示では、選択した用語と直接隣接した用語から成る誘導部分グラフに、選択中の分類・配置方法と計算条件を適用します。

スペクトル分類は Bᵢⱼ = Aᵢⱼ − kᵢkⱼ/(2m) を用います。群 g の再分割では Bᵍᵢⱼ = Bᵢⱼ − δᵢⱼΣₖ∈g Bᵢₖ とし、元のグラフの次数と m を保ちます。**代数的に最大の固有値**に対応する固有ベクトルの符号から s ∈ {−1,+1} を作り、ΔQ = sᵀBᵍs/(4m) > 1e-12 のときだけ分割します。孤立点はそれぞれ単独の群とし、つながっていない成分は別の群から処理を始めます。Q が増える分割が存在するには、正の固有値が必要です。固有ベクトルを符号に置き換えた後も、実際の ΔQ を確認します。分割後に頂点を移動して改善する処理は実装していません。

スペクトル配置の元の座標は [Hall (1970)](https://doi.org/10.1287/mnsc.17.3.219) の二次形式に対応し、XᵀX = I、Xᵀ1 = 0 のもとで tr(XᵀLX) を最小化します。頂点が1つの場合は原点に置き、2つの場合は1軸だけを使います。

固有値の計算には対称 Jacobi 法を使い、非対角成分の Frobenius ノルムが 1e-12 × max(1, ‖M‖F)（M は対象の対称行列）以下になったら収束とみなします。行列全体を80回走査しても収束しなければ、エラーにします。

固有値が重複する場合は、固有空間内の軸が一意に決まらず、構造上対称な用語が同じ点に置かれることもあります。表示時には、中心間の距離が42以上になるまでらせん状に位置をずらし、その後で成分を並べます。この補正や縦横の拡大・縮小を行った後の座標では、元の二次形式での最適性は保証しません。

## 比較と再計算

比較表には、選択中の表示範囲と絞り込み条件に合うグラフを使い、既定の計算条件で求めた初期配置の指標を表示します。全体表示では孤立点を含むすべての用語を、周辺表示では選択した用語の誘導部分グラフを計算に含めます。グループ別の配置には、選択中の分類を使います。計算条件を変えたり、手動で用語を動かしたりしても、表の値には反映されません。

- 直線の交差数：自己参照、方向、重複を取り除いてから、直線の交差を数えます。端点を共有する箇所、接触、同一直線上の重なりは含めません。画面上の曲線の交差数とは異なります。
- 正規化した平均辺長：辺の長さの平均を、配置全体を囲む長方形の対角線の長さで割ります。孤立した用語の位置も値に影響します。
- 辺長の変動係数（CV）：辺の長さの標準偏差を平均で割り、長さのばらつきを表します。

計算条件は方式ごとに保持し、「再計算」で反映します。「配置を初期状態に戻す」を選ぶと、現在の表示で手動調整した座標と、現在の方式の設定が初期状態に戻ります。計算結果と手動で調整した座標は、個別に保持します。再計算と比較は Worker で実行し、最後に要求した計算の結果を表示します。

## 検証

検証には、既知のクリーク、循環、DAG、空のグラフ、孤立した用語を使います。実装とは独立した式で、無向・有向 Q、定常流の流入量と流出量の一致、エントロピーから求めた符号長、距離ストレスの単調減少、辺が1本の場合の厳密解、縮尺を変えても交差数が変わらないことを確認します。

固有値の残差と直交性、4頂点の環状グラフの配置エネルギー、4つのクリークの再帰的な分割も検証します。貪欲法が停止した時点で改善可能な群の結合が残らないこと、入力順や重複辺の有無で結果が変わらないことも確認します。全56通りで用語の所属と座標がそろうことと、分類に依存しない配置の結果が一致することを検証します。方式や設定の切り替え、グラフと原文の根拠の保持は、ブラウザーでも確認します。

手法の網羅性、採用していない手法、各実装の保証と限界は、[数学的な根拠と検証](algorithm-review.md) に記載しています。
