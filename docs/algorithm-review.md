# 分類と配置の数学的な根拠・検証（2026-10-15）

## 確認結果と変更内容

このプロジェクトでは、用語の参照関係をグラフでたどり、分類や配置の結果を比較できます。手法の網羅性は、目的関数や構造の捉え方が異なる系統を比較できるかどうかで評価しました。

無向・有向モジュラリティ、Louvain の移動と集約、定常流、map equation の式を確認したところ、係数や方向の誤りは見つかりませんでした。一方で、配置の数学的な根拠とスペクトル法の比較が不足していたため、次の変更を行いました。

- 距離ストレスの計算を、独自の同時緩和と直線探索から、上界を最小化する stress majorization に変更しました。出典も、この方法を扱う論文に変更しました。
- Newman のスペクトル分類と、Hall のラプラシアンによる配置を追加しました。
- 交差判定に固定のしきい値を使っていたため、同じ図形でも縮尺によって交差数が変わる問題を修正しました。
- 群間隔の倍率を変えると群の半径まで縮まり、群の領域が重なる問題を修正しました。
- 入力順、重複辺、自己参照の有無で結果が変わらないように、入力を正規化しました。区切り文字を含む ID の辺を混同する問題も修正しました。

分類では、密度、到達可能性、隣接ノードのラベルの一致、情報流、スペクトル分割を比較できます。配置では、力学、距離、スペクトル、階層、円形、放射状の方法を比較できます。主要な系統を比較する用途には対応していますが、分類が統計的に妥当であることを保証するものではありません。

## 分類の根拠と保証

Aᵢⱼ は i → j の重複を除いた辺を、m は分析に使う辺の数を表します。無向グラフに変換するときは、相互参照を1本にまとめます。

| 実装 | 数学的な根拠 | 保証の範囲と注意点 |
| --- | --- | --- |
| 無向の貪欲結合 | Q = Σc [e꜀/m − (K꜀/2m)²]。e꜀ は群内の無向辺の数、K꜀ は次数の合計を表す。群間の辺の数 eₐᵦ に対する増加量は eₐᵦ/m − KₐKᵦ/(2m²) となる | 増加量が正の場合に結合する。すべての分割の中で最大の Q が得られる保証はない。CNM の高速ヒープや、結合過程全体の樹形図は実装していない |
| 有向の貪欲結合 | Q = Σc [e꜀/m − K꜀out K꜀in/m²]。増加量は (eₐᵦ+eᵦₐ)/m − (Kₐout Kᵦin+Kᵦout Kₐin)/m² となる | 有向 Q を使う。探索には群の結合を使い、Leicht–Newman 論文のスペクトル法は実装していない |
| Louvain | 節点 v を取り除いた後、群 C への挿入スコア kᵥ,C − kᵥΣC/(2m) を比較する。集約行列の対角成分に内部辺の両方向の重みを保持し、次数の合計 2m と Q を保つ | 処理順を固定し、各レベルで最大100回反復する。解像度は1とする。群の連結性や、すべてのノードの移動を考慮した最適性は保証しない |
| スペクトル分類 | 元の次数と m を保った Bᵍ について、代数的に最大の固有値に対応する固有ベクトルから分割候補を作る。実際の ΔQ が正なら採用する | 離散的な分割を連続変数の問題に緩和しているため、最大の Q は保証しない。使う固有値は代数的な最大値であり、絶対値の最大値ではない |
| ラベル伝播 | 隣接ノードで最も多いラベルに順次更新する。同数の場合に現在のラベルを保つことで、ラベルが一致する辺の数を減らさない | Q は結果を比較するために計算する。処理順を固定し、反復は100回までとする。この上限までの実行は、収束の証明にはならない |
| 強連結成分 | Tarjan 法を使い、互いに到達できるノードの同値類を厳密に求める | 長い参照経路を通じて行き来できる場合も、同じ群になる。密度や意味の類似性を表す分類ではない |
| 情報流 | α=.85 として Pᵢⱼ = (1−α)/n + αAᵢⱼ/kᵢout とする。出辺がない場合は1/n とする。pP=p、Fᵢⱼ=pᵢPᵢⱼ、L=qH(Q)+Σc(p꜀+q꜀)H(P꜀) を使う | テレポーテーションも記録する2段階モデルを使い、群の結合によって探索する。Infomap の局所移動や階層探索は実装していない。孤立点もテレポーテーションで他の点との流れを持つため、同じ群になる場合がある |

map equation は、xlog(x)=x log₂x、xlog(0)=0 と置き、L=xlog(Σq꜀)−2Σxlog(q꜀)+Σxlog(p꜀+q꜀)−Σxlog(pᵢ) に展開して実装しています。独立したエントロピーの計算と照合しています。一様なテレポーテーションにより、ノードを含むグラフの定常分布は一意になります。ただし、語の意味に照らして妥当な群の数が一意に決まるわけではありません。

すべての辺の向きを反転しても、無向 Q は変わりません。有向 Q も、すべての辺を同時に反転すれば、入次数と出次数の積、群内の辺の数が保たれるため変わりません。一部の辺だけを反転した場合は、一般に変わります。無向 Q、有向 Q、符号長は尺度が異なるため、数値をそのまま比べて順位を付けることはできません。モジュラリティには解像度の限界があり、小さく密な群が1つにまとめられる場合があります。

式と原論文へのリンクは、[手法と実装](graph-research.md) に記載しています。

## 配置の根拠と保証

| 実装 | 数学的な根拠 | 表示のための処理と保証の範囲 |
| --- | --- | --- |
| Fruchterman–Reingold | 距離 r での反発力を ρk²/r、辺による引力を r²/k とする。k=√(490000/n) とし、温度で移動量を制限しながら、その上限を一定の割合で減らす | 原論文の力の式を使う。エネルギーや交差数の単調減少は保証しない。距離が極端に小さい場合に備え、計算上の下限を設ける |
| 距離ストレス | S=Σᵢ<ⱼ dᵢⱼ⁻²(‖xᵢ−xⱼ‖−dᵢⱼ)² の上界を最小化する | 並進の自由度を取り除いた連立方程式を、Cholesky 分解で解く。採用した各反復で S は増加しない。表示時に成分を移動しても成分内の距離は保たれるが、拡大すると距離は変わる |
| スペクトル配置 | L=D−A、XᵀX=I、Xᵀ1=0 の制約の下で tr(XᵀLX) を最小化する。0以外の固有値を小さい順に2つ選び、対応する固有ベクトルを軸に使う | 元の座標は二次形式で表した緩和問題の解となる。線の交差数を最小化する保証はない。近接点を離す処理や、縦横で倍率の異なる拡大・縮小は、表示のために後から行う |
| 強連結成分の階層 | 強連結成分を縮約した DAG の最長経路に基づき、層を割り当てる。成分の並び順は Sugiyama 系と同じ方法で調整する | 成分間の辺は前方の層へ進む。並び順は縮約した成分の間の交差を減らすもので、用語ごとの直線の交差数は保証しない。幅を抑えるために折り返すので、同じ成分内でも高さが異なる場合がある |
| Sugiyama 系 | 強連結成分ごとに Eades–Lin–Smyth の貪欲法で帰還辺集合を選んで反転し、DAG を作る。network simplex で Σ(λ(v)−λ(u)) を最小化して層を割り当てる。仮想ノード、重み付き中央値、隣接交換で並び順を決める | 反転する辺は成分の内側に限られるが、その本数が最小である保証はない。層の割り当ては、辺の長さの合計が最小となる整数解である。全探索との比較で検証する。並び順は交差数の最小値を保証しない。辺の反転は計算中だけ行い、元の方向で描画する。仮想ノードを通る経路は描画しない |
| 放射状・円形・グループ別 | 幅優先探索（BFS）の距離による層、次数順の円周配置、黄金角のらせんと領域の配置を使う | それぞれの規則に従って位置を決める。共通の目的関数を最適化する方法ではない |

交差数は、直線が互いを横切る箇所を数えます。端点を共有する箇所、接触、同一直線上の重なりは含めません。座標の差を配置全体の対角線の長さで正規化してから、符号を比較します。浮動小数点で計算するため、ほぼ同一直線上にある極端な入力について、厳密な幾何判定は保証しません。この指標では、画面上の曲線の交差やラベルの重なりは評価しません。

## 採用していない主要手法

| 系統・手法 | 検討結果と採用する条件 |
| --- | --- |
| [Leiden](https://arxiv.org/abs/1810.08473) | 次に検討する有力な候補。Louvain で群が非連結になる問題を防ぐため、分割の改善処理と集約の条件を含めて実装する必要がある。現在の Louvain は、群の連結性を保証しない |
| [Normalized cut と k-way spectral clustering](https://arxiv.org/abs/0711.0189) | 群数を固定したい場合や、偏りの少ない分割を求める場合の候補。今回は、群数を指定せず、Q の改善で停止できる Newman 法を採用した。目的関数もそれぞれ異なる |
| [Girvan–Newman](https://arxiv.org/abs/cond-mat/0112110)、MCL、Walktrap | 媒介中心性に基づく辺の除去、流れの拡張・膨張、ランダムウォークの距離に基づく凝集は実装していない。階層構造や歩行モデルをさらに比較する際の候補となる |
| [確率的ブロックモデル（SBM）](https://arxiv.org/abs/1310.4377) | 統計モデルの選択、異なる群どうしが結び付きやすい構造の分析、群数の推定が必要な場合の候補。現在の目的関数の値は、有意性検定の結果として扱えない |
| k-means、DBSCAN、一般的な階層クラスタリング | 特徴空間と距離を別途定義する必要がある。画面上の距離を入力にすると、配置方法によって分類が変わってしまう。語の意味をベクトルで表す機能を追加する際に検討する |
| Kamada–Kawai、ForceAtlas2、マルチレベル力学配置 | 距離を重視する方法には stress majorization を、力のモデルには Fruchterman–Reingold を採用した。大規模なグラフや、連続操作時の応答性への対応が必要になった場合に、専用のモデルや近似を検討する |
| 古典的 MDS、平面・直交配置、木構造専用の配置 | 固有値を使う MDS とラプラシアンによる配置は、異なる方法である。一般的な有向循環グラフには、平面性や木構造を前提とする方法をそのまま適用できないため、今回は採用していない |

## 検証範囲

`tests/analysis.test.ts` では、無向・有向 Q を独立した二重和で求め、エントロピーによる符号長 L、確率流の保存、貪欲結合の停止条件を確認します。既知のクリークの分割、3頂点で作れるすべての有向グラフの相互到達性、2頂点の力学配置の解析解、ストレスの単調性、退化したグラフ、入力順を変えた場合の結果、分類と配置の全56通りも検証します。

`tests/numerics.test.ts` では、連立方程式の残差、固有値の残差と直交性、符号の異なる固有値、既知の配置エネルギーを確認します。ブラウザーで全組み合わせを試すテストでは、登録情報から方式を取得し、追加された方式も検証できるようにしています。

離散最適化には近似的な探索手法を使い、数値計算には浮動小数点を使います。このため、理論上の保証、実装で反復を打ち切る条件、表示のための後処理を、それぞれ説明しています。有限個のテストだけで、すべてのグラフでの動作を証明することはできません。密行列の固有値計算と Cholesky 分解には、おおむね O(n³) の時間と O(n²) の記憶領域が必要です。大規模なネットワークを扱う場合は、疎行列に対応した計算方法を検討する必要があります。

2026年10月15日の検証では、単体テスト23件（全体実行の21件と、追加した2件の個別実行）、公開用ビルド、Chromium・WebKit・iPhone 相当の操作テスト29件、描画性能テスト3件が成功しました。ブラウザー固有の操作に関する4件は、テストで定めた条件に従ってスキップしました。Firefox は、記録済みのローカル起動の問題があったため実行せず、CI の検証対象としました。
