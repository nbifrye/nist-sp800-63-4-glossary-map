# 分類・配置の数学レビュー（2026-10-15）

## 判断と今回の変更

このプロジェクトは、用語の**参照グラフ**を探索・比較するものです。文の意味ベクトルをクラスタリングするものではありません。主要手法の網羅性は、手法名の数ではなく、目的関数と構造の見方が異なる系統を比較できるかで評価しました。

既存の無向／有向モジュラリティ、Louvain の移動・集約、定常流と map equation の式に、レビューで確認できる係数や方向の誤りはありませんでした。ただし、配置の数学的根拠とスペクトル法の比較が不足していました。次を改善しました。

- 距離ストレスの独自の同時緩和・直線探索を、上界を最小化する stress majorization に置換。出典を直接対応する論文に変更。
- Newman のスペクトル分類と、Hall のラプラシアンによる配置を追加。
- 交差判定の固定閾値によって、同じ図形でも縮尺により交差数が変わる問題を修正。
- 群間隔の倍率が群の半径まで縮め、群領域が重なる問題を修正。
- 入力順・重複辺・自己参照に対して結果が変わらないよう正規化。区切り文字を含む ID の辺が混同される問題も修正。

これで密度・到達性・局所合意・情報流・スペクトル分割、および力学・距離・スペクトル・階層・円／放射の主要な比較軸を備えます。**主要な系統を比較する探索ツールとしては十分ですが、著名な手法をすべて実装したものでも、統計的に正しい概念分類を保証するものでもありません。**

## 分類の根拠と保証

Aᵢⱼ は i → j の一意の辺、m は分析に使う辺数です。無向化では相互参照を1本にまとめます。

| 実装 | 数学的根拠 | 保証しないもの・注意点 |
| --- | --- | --- |
| 無向の貪欲結合 | Q = Σc [e꜀/m − (K꜀/2m)²]。e꜀ は群内の無向辺数、K꜀ は次数和。群間辺数 eₐᵦ に対する増分は eₐᵦ/m − KₐKᵦ/(2m²) | 正の増分だけ結合。全分割中の最大 Q は保証しない。CNM の高速ヒープや全樹形図は未実装 |
| 有向の貪欲結合 | Q = Σc [e꜀/m − K꜀out K꜀in/m²]。増分は (eₐᵦ+eᵦₐ)/m − (Kₐout Kᵦin+Kᵦout Kₐin)/m² | 有向 Q を用いるが、Leicht–Newman 論文のスペクトル探索ではない |
| Louvain | 節点 v の除去後、群 C への挿入スコア kᵥ,C − kᵥΣC/(2m) を比較。集約行列の対角に内部辺の両方向の重みを保持し、次数和 2m と Q を保存 | 訪問順固定、各レベル最大100反復、解像度1。群の連結性や全ノード移動に対する最適性は保証しない |
| スペクトル分類 | 元の次数と m を保った Bᵍ の最大代数固有ベクトルから候補分割を作り、実際の ΔQ が正なら採用 | 離散分割を連続緩和しているため、最大 Q は保証しない。絶対値最大の固有値を選ぶべきではない |
| ラベル伝播 | 隣接ノードの最多ラベルへ非同期更新。同数で現ラベルを保つ場合は一致辺数を減らさない | Q の最適化ではない。Q は比較用の事後評価。訪問順固定、100反復上限があり収束の証明として扱わない |
| 強連結成分 | Tarjan 法で相互到達性による同値類を厳密に求める | 密度や意味的な類似性ではない。長い参照経路でも同じ群になり得る |
| 情報流 | α=.85 として Pᵢⱼ = (1−α)/n + αAᵢⱼ/kᵢout。出辺なしでは1/n。pP=p、Fᵢⱼ=pᵢPᵢⱼ。L=qH(Q)+Σc(p꜀+q꜀)H(P꜀) | テレポートを記録する2段階モデル。群結合だけなので Infomap の局所移動・階層探索とは異なる。孤立点もテレポートで他点と流れを持ち、同じ群になり得る |

map equation の実装は xlog(x)=x log₂x、xlog(0)=0 として L=xlog(Σq꜀)−2Σxlog(q꜀)+Σxlog(p꜀+q꜀)−Σxlog(pᵢ) に展開したものです。独立したエントロピー計算で照合しています。一様テレポートによって非空グラフの定常分布は一意ですが、意味的に妥当な群数が一意になるわけではありません。

無向 Q は全辺の反転に不変です。有向 Q も**全辺を同時に**反転すれば入出次数の積と群内辺数が保存されますが、一部の辺だけの反転には一般に不変ではありません。無向 Q と有向 Q と符号長を同じ尺度として順位付けしません。モジュラリティには解像度限界があり、小さな密な群がまとめられる場合があります。

式と原論文へのリンクは [手法と実装](graph-research.md) に記載しています。

## 配置の根拠と保証

| 実装 | 数学的根拠 | 表示と最適化の区別 |
| --- | --- | --- |
| Fruchterman–Reingold | 距離 r で反発の大きさ ρk²/r、辺の引力 r²/k。k=√(490000/n)。温度で移動量を制限し線形冷却 | 原論文の力の形を使用。エネルギーや交差数の単調減少は保証しない。微小距離には数値的な下限を置く |
| 距離ストレス | S=Σᵢ<ⱼ dᵢⱼ⁻²(‖xᵢ−xⱼ‖−dᵢⱼ)² の majorization | Cholesky で並進自由度を除いた連立方程式を解く。各採用反復で S は非増加。表示用の成分移動は距離を保存するが拡大は保存しない |
| スペクトル配置 | L=D−A、XᵀX=I、Xᵀ1=0 の制約下の tr(XᵀLX)。非零固有値が最小の2軸を使用 | 原座標は二次形式の緩和問題の解。交差最小化ではない。近接点の補正と異方的な拡縮は最適化の一部ではない |
| SCC 階層 | 縮約 DAG の最長路による順位 | SCC 間の辺は前進する。SCC 内は同じ高さとは限らず、幅を抑える折り返しがある |
| Sugiyama 系 | DFS 戻り辺の反転で DAG 化、最長路順位、仮想点と重心順序 | 反転は計算内だけ。描画は元の方向の辺。重心スイープは交差最小化の厳密解ではなく、仮想点を通る経路も描画しない |
| 放射・円・群別 | BFS 距離による層、次数順の円周、黄金角の螺旋と領域配置 | 位置を決める規則は明確だが、共通の目的関数を最適化しているとは主張しない |

交差数は直線同士の真の交差だけを数え、共有端点・接触・共線重なりを除きます。座標差を配置の対角長で正規化して符号を比較します。浮動小数点計算なので、ほぼ共線の極端な入力に対する厳密幾何述語の保証はありません。画面の曲線・ラベルの重なりとは異なる指標です。

## 未採用の主要手法と採否

| 系統／手法 | 今回の扱いと理由 |
| --- | --- |
| [Leiden](https://arxiv.org/abs/1810.08473) | 有力な次の候補。Louvain の非連結群を防ぐ refinement と集約の条件を含めて実装する必要がある。単に連結成分へ分ける処理を Leiden と呼ばない。現状の Louvain には連結性保証がないことを明記 |
| [Normalized cut と k-way spectral clustering](https://arxiv.org/abs/0711.0189) | 固定群数やバランスのよい切断を要求する用途の候補。今回は群数を指定せず Q の改善で停止できる Newman 法を採用。両者の目的関数は異なる |
| [Girvan–Newman](https://arxiv.org/abs/cond-mat/0112110)、MCL／Walktrap | 媒介中心性による辺除去、流れの拡張・膨張、歩行距離による凝集は未収録。階層や歩行モデルをさらに比較する際の候補。情報流と貪欲 Q だけでこれらを再現したとは扱わない |
| [確率的ブロックモデル（SBM）](https://arxiv.org/abs/1310.4377) | 統計的モデル選択、非同類選好型の構造、群数推定を目的にする場合に必要。現在の探索表示の目的関数スコアに有意性検定の意味を付与しない |
| k-means、DBSCAN、一般の階層クラスタリング | 特徴空間と距離の定義が別途必要。参照グラフに画面上の座標距離を入力すると配置結果に依存してしまう。語義の埋め込みを扱う拡張時に検討 |
| Kamada–Kawai、ForceAtlas2、マルチレベル力学配置 | KK と同系統の距離目的を majorization で扱い、力のモデルは FR を代表として採用。大規模化・連続操作時の応答性が必要になれば専用のモデル／近似を検討 |
| 古典 MDS、平面・直交配置、木専用配置 | 固有値を使う MDS とラプラシアン配置は別物。一般の有向循環グラフには平面性・木構造の仮定が成立しないため、現状は未採用 |

## 検証範囲

`tests/analysis.test.ts` は、無向／有向 Q の独立した二重和、エントロピーによる L、確率流の保存、貪欲結合の停止条件、既知のクリーク分割、3頂点の全有向グラフの相互到達性、2頂点の力学配置の解析解、ストレスの単調性、退化グラフ、入力順の不変性、全56組を検証します。`tests/numerics.test.ts` は連立方程式の残差、固有値の残差・直交性・符号の異なる固有値、既知の配置エネルギーを検証します。ブラウザーの全組合せテストは登録表から方式を取得し、追加方式が検証から漏れないようにしています。

有限個のテストはすべてのグラフに対する証明ではありません。離散最適化はヒューリスティック、数値計算は浮動小数点近似であり、理論上の保証、実装上の打切り、描画用の後処理を分けて説明します。密行列の固有値計算と Cholesky 分解には概ね O(n³) の時間と O(n²) の記憶が必要で、大規模ネットワーク向けの疎行列法ではありません。

今回の検証では、単体23件（全体21件と追加2件の個別実行）、本番ビルド、Chromium・WebKit・iPhone相当の操作29件と描画性能3件が成功しました。ブラウザー固有の操作に関する4件は定義どおりスキップしています。Firefox は既知のローカル起動問題があるため今回実行せず、CI の対象として保持しています。
