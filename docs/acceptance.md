# 要件と実装・検証の対応

Issue #1 と追加コメント #6072533111 の要件について、現在の実装と検証内容をまとめた資料です。対象の原典は、2026年10月9日に取得した NIST SP 800-63-4 シリーズの正式版4文書です。

ここに記載した自動テストと Codex による確認は、独立した人間による査読を意味しません。確認の履歴は [内容確認の履歴](../data/review-history.json)、開発と更新の手順は [README](../README.md) を参照してください。

## 収録内容と参照の根拠

| 要件 | 現在の実装 | 検証内容 |
| --- | --- | --- |
| 4文書の用語集を全文収録し、出典と版を示す | `sources/` の保存済み HTML から用語集だけを抽出。189用語・出典別の定義496件 | 抽出処理とは別の方法で見出し・定義の件数と全文を照合。文書別の定義数は189・89・124・94件 |
| 同じ見出しをまとめ、定義は出典別に保持する | 見出しごとに用語を集約し、文書と用語の組み合わせで定義 ID を作成 | 見出しと用語 ID の一意性、全定義の出典を照合 |
| 原文・訳文・版・取得日を確認できる | 出典別の定義、日本語訳、開閉式の英語原文、原典へのリンク、サイト情報 | 複数文書の表示、出典の絞り込み、定義へのリンクをブラウザーで確認 |
| 英語の見出しで検索できる | `filterTerms` で検索。見出し末尾の括弧内略称は対象外 | 見出しの検索、文書別の絞り込み、略称だけの検索で該当しないことを確認 |
| 参照先と参照元を調べられる | 原文中のリンクと方向別の参照一覧。出典・種類ごとに絞り込み | 参照元の定義、出典、原文位置と対応先を照合 |
| 原典の明示参照と独自の語句対応を区別する | 原文の表現・位置・斜体情報・判定規則を保存。種類を文字と線種で表示 | 全1,706か所の原文一致、範囲の非重複、対応先 ID の存在を確認 |
| 対応付けの基準と限界を説明する | サイト情報、グラフの操作説明、README に記載 | 単語境界、最長表現、単数形・複数形、大文字・小文字、斜体の判定をテスト |
| 訳文で条件・限定・否定・例を保つ | 189件の原文に対応する訳文と確認情報を保存 | 原文・訳文・ハッシュの対応を自動確認。意味と表現は Codex が原文と照合 |
| 自己参照、循環、文書をまたぐ参照を残す | 全4文書の見出しと照合し、参照を再帰的に展開せず保持 | `validation` と `attribute validation` の相互参照、文書をまたぐ照合を確認 |
| 原文更新と訂正を追跡できる | 原典と定義の SHA-256、確認履歴、Git 履歴、原文差分の確認スクリプト | 原典ハッシュの不一致や対応する訳文の欠落でビルドが失敗することを確認 |

語句の一致だけでは意味の違いを判別できません。たとえば一般的な動詞の `control` が、管理策を指す見出し `controls` に対応する場合があります。独自の語句対応であることと原文の根拠を示し、概念上の依存関係や学習順序とは区別します。

## 関係グラフと手法の比較

| 要件 | 現在の実装 | 検証内容 |
| --- | --- | --- |
| 全用語と全参照を俯瞰できる | 全189用語と512件の方向付き参照を表示し、全1,706か所の根拠を保持 | 集約後もすべての根拠が残ることと、画面の用語数・参照数を照合 |
| 用語から定義を読める | クリック・タップ・Enterで選択し、同じ画面の詳細パネルに定義を表示。「用語集で開く」で画面を移動 | 選択した見出し・訳文・原文を照合。原文中の用語から同じパネル内で定義をたどれることを確認 |
| 参照の根拠を読める | 線の選択と参照一覧の両方から、出典別の根拠を表示 | 原文位置、参照元の定義、対応先を照合 |
| 全体表示と周辺表示を切り替えられる | 周辺表示は選択用語と直接つながる全用語、およびそれらの間の参照を表示 | 別に計算した隣接用語の集合と照合。中央配置と全体表示への復帰を確認 |
| 拡大縮小・表示位置の移動・自由配置ができる | ボタン、ホイール、ピンチ、背景や用語のドラッグ、矢印キー | 座標や拡大率の変化、線と背景の追従、画面切り替え後の配置保持を確認 |
| 用語グループと配置方法を比較できる | 検出6方式と配置7方式を別々に選択し、42通りを表示 | 全組み合わせの所属・座標・根拠の保持、再生成の一致、メニューとデータの一致を確認 |
| 分析方法と指標の意味を確認できる | 「手法を比較」に説明、論文、グループの集計、配置の交差数・線の長さを表示 | 既知のグラフと独立した計算で、モジュラリティ、強連結成分、定常流、符号長、距離ストレス、交差数を検証 |
| 配置の計算条件を調整できる | 方式ごとの条件を保持し、「再計算」で更新。「初期値に戻す」で保存済み配置を復元 | 計算の再現性、入力範囲、所属の保持、初期配置への復元、操作後のフォーカスを確認 |
| 自動分類の限界を示す | 用語グループが NIST の公式な分類ではないことを明示 | 注記の表示と、絞り込みで所属が変わらないことを確認 |

用語グループの検出と初期配置の詳細は [論文調査と実装の対応](graph-research.md) を参照してください。公式 Infomap の探索処理、階層 Infomap、Leiden、network simplex、距離ストレスの Newton 法や厳密な stress majorization は実装していません。

## 読み込み・描画性能・公開

自動テストの対象は、Playwright に含まれる Chromium、Firefox、WebKit のデスクトップ表示と、iPhone 13 相当の WebKit 表示です。複数タッチの入力注入は Chromium で検証しています。iPhoneなどの実機での手動検証や、過去のブラウザーバージョンへの対応確認は行っていません。

全189用語・496定義・1,706か所の参照を読み込む状態で、次の項目を確認します。

- 読み込み完了と検索結果の更新は、CIのテストで5秒以内を基準とします。実際の応答時間は端末や通信環境に左右されます。
- 12回の連続ズーム描画をブラウザー内で測定します。合計1.5秒未満、補間した95パーセンタイルの応答100ms未満、最大250ms未満を基準とします。テスト制御の通信往復と画面トレースの負荷を除くため、性能測定はブラウザーを1つずつ起動し、トレースなしで実施します。
- 初回のサイズ変更通知を遅らせても、その前に行ったズームが初期表示に戻されないことを検証します。
- HTTP 500やデータの欠落を検出した場合は、エラーと再読み込み操作を示します。配置データだけの失敗では、検証済みの用語集と参照一覧を引き続き閲覧できます。
- CSP、テキストとしての描画、公開ファイルの限定、原文ハッシュ、生成データの差分、公開ジョブの権限を確認します。
- GitHub Actionsでビルドとテストに成功した公開用ファイルを、GitHub Pagesへ公開します。機能・アクセシビリティ検証では失敗時のトレースを保存します。
