# 要件と実装・検証の対応

[Issue #1](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1) の本文、[全体グラフの追加要件](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1#issuecomment-6072533111)、[方式比較の追加要件](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1#issuecomment-6180078546) に対する実装と検証をまとめています。グラフの単独利用と、Zenn への埋め込みも設計に含めています。

| 要件 | 実装 | 主な検証 |
| --- | --- | --- |
| 4文書の用語集を収録し、出典ごとの定義、原文、訳文を読める | 保存済みの HTML から定義を抽出し、原文のハッシュで訳文を対応付ける | `tests/data.test.ts` で段落、リスト、斜体、リンク、Unicode、出典ごとの件数、ハッシュ、再生成結果を確認する |
| 同じ見出しをまとめ、定義と根拠を出典ごとに保持する | `model.ts` で用語、定義、参照箇所を管理し、方向付きの辺を作る | 全定義の原文ハッシュと、集約後もすべての参照箇所が残ることを確認する |
| 見出しで検索し、出典で絞り込める。略称は検索対象に含めない | グラフ内に検索結果を表示し、「表示設定」で出典を選べる | ブラウザーで検索と出典ごとの定義を確認する |
| 参照元、参照先、根拠となる原文、原典を確認できる | 詳細欄に原文へのリンクと方向別の参照一覧を設け、グラフの線からも開ける | 参照先、原文中の範囲、出典、参照の種類を検証し、ブラウザーで根拠から定義へ移動する |
| 単語の境界、複合語、単数形・複数形、大文字・小文字、循環、文書をまたぐ参照を扱う | 定めた照合基準をすべての見出しに適用する | テスト用の例で、最長一致、単語の境界、単数形・複数形、略称の除外、斜体、See の扱いを確認する |
| 内容の確認履歴を残し、更新を追跡できる | 原典のハッシュ、訳文の確認情報、`content/reviews.json`、Git の履歴で記録する | ビルド時に原典、訳文、参照の整合性を検証し、確認履歴の表示を確認する |
| 全体と選択した用語の周辺を、方向付きの参照で表示する | Cytoscape.js と誘導部分グラフを使う | 全用語と全参照箇所を保持し、隣接する用語の集合を独立した計算と照合する |
| 周辺の部分グラフにも選択した配置方法を適用する | 表示中の部分グラフを Worker に渡し、分類、配置、比較を計算する | 全8配置の描画座標、計算条件、比較表、用語・範囲・絞り込みの切り替え、手動座標の保持、URL からの復元、孤立点をブラウザーで確認する |
| 表示の移動、拡大・縮小、自由な配置ができ、用語やグループを調べられる | グラフの操作と HTML の一覧から利用できる | キーボード操作後の描画、定義・グループ一覧・根拠の閲覧、Chromium のタッチ入力によるページスクロールとグラフ操作の切り替えを確認する |
| 出典と参照の種類に応じて計算する | 絞り込み条件で分析に使う参照を更新し、分類、配置、比較を再計算する | 全出典と参照種類の組み合わせを照合し、Worker の結果、比較表、URL からの復元をブラウザーで確認する |
| 分類方法と配置方法を独立して選び、比較できる | 7種類の分類と8種類の配置を、共通の Worker で計算する | 既知のグラフの独立した計算、全56通りの結果、グループ別以外の配置の独立性を検証し、ブラウザーですべて選択する |
| 各方式の計算条件と指標を理解できる | 手法の説明と比較表を表示し、再計算と初期状態への復元を提供する | 目的関数、定常流、符号長、ストレス、交差数、URL からの復元、再計算を確認する |
| 翻訳と分類が非公式であること、参照が概念の依存関係を示さないことを伝える | ヘッダー、詳細欄、「表示設定」に説明を置く | 表示内容と自動アクセシビリティ検査で確認する |
| キーボード、スクリーンリーダー、狭い画面で利用できるようにする | ラベル、HTML の参照一覧、フォーカス可能な詳細欄、コンテナクエリーを使う | axe の WCAG 2.1 AA 検査と、幅 320・760・1440px で通常サイトと単独ページの表示を確認する |
| 操作に応答し、失敗した場合にその状態を伝える | Worker とキャッシュを使い、古い計算結果を除外する。失敗時はエラーと再試行ボタンを表示する | 連続12回のズームが合計1.5秒未満、95パーセンタイルで100ms未満、最大250ms未満であることと、Worker の起動を禁止した場合の表示を確認する |
| グラフを単独で利用し、Zenn に埋め込める形で配布する | `embed.html` と、データ・Worker を同梱した JS/CSS を生成し、公開時に固定版を保持する | 別オリジンの iframe から外部 JS/CSS を読み込み、選択、再配置、リソースの破棄を検証する |
| 静的ファイルを安全に配信し、GitHub Pages に公開する | テキストでの描画と CSP を使い、CI から公開用ビルドを配信する | 型チェック、単体テスト、公開用ファイルのブラウザーテストを実行し、公開権限をデプロイ処理に限定する |

ローカルでは、Chromium、WebKit、iPhone 相当の WebKit を検証してきました。Firefox も CI の対象ですが、この macOS 環境では「Could not find profile folder」というエラーでブラウザーが起動しない問題が記録されています。独立した人間による翻訳の査読、実機と実際のスクリーンリーダーによる全操作、CodePen での公開、Zenn の実際の記事でのプレビューは、自動テストの範囲に含みません。
