# 要件と実装・検証

対象は [Issue #1](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1) の本文、[全体グラフの追加要件](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1#issuecomment-6072533111)、[方式比較の追加要件](https://github.com/nbifrye/nist-sp800-63-4-glossary-map/issues/1#issuecomment-6180078546) です。さらに、グラフ単独の流用と将来の Zenn 埋め込みを設計対象としています。

| 要件 | 実装 | 主な検証 |
| --- | --- | --- |
| 4文書の Glossary、出典別定義、原文と訳文 | 保存済み HTML を抽出し、原文ハッシュで訳文を結合 | `tests/data.test.ts`：段落・リスト・斜体・リンク・Unicode、出典別件数、ハッシュ、再生成 |
| 同じ見出しの集約、定義・根拠を出典別に保持 | `model.ts` の用語・定義・参照箇所、方向別辺の導出 | 全定義の原文ハッシュ、全出現箇所を失わない集約 |
| 見出し検索、出典で絞り込み、略称は対象外 | グラフ内の検索結果と表示設定の出典選択 | 検索・出典別定義のブラウザーテスト |
| 参照元と参照先、原文の根拠と原典 | 詳細欄の原文リンク・方向別一覧、線の選択 | 参照先・原文範囲・出典・明示／語句対応の検証、ブラウザーで根拠から定義へ移動 |
| 単語境界・複合語・単複・大小文字・循環・文書横断 | 明示した基準で全見出しと照合 | 最長一致・境界・単複・略称除外・斜体・See のフィクスチャ |
| 内容の確認履歴と更新追跡 | 原典ハッシュ、訳文の確認情報、`content/reviews.json`、Git | ビルド時の原典・訳文・参照の整合性検証、確認履歴の表示 |
| 全体グラフ、方向付き参照、局所グラフ | Cytoscape.js と誘導部分グラフ | 全用語・全参照箇所の保持、独立に求めた隣接集合との照合 |
| パン・ズーム・自由配置、用語と群の探索 | 描画操作と HTML の選択・一覧 | キーボード操作後の描画変化、定義・群一覧・根拠の閲覧、Chromium のネイティブ相当のタッチ入力で記事スクロールとグラフ操作の切り替え |
| 複数の分類と配置を独立して比較 | 分類7方式、配置8方式、共通 Worker | 既知グラフの独立計算、全56組、群別以外の配置の独立性、ブラウザーで全組を選択 |
| 方式・計算条件・指標の説明 | 手法の登録情報と比較表、再計算・リセット | 目的関数、定常流、符号長、ストレス、交差数、URL復元と再計算 |
| 公式分類・翻訳・概念依存との区別 | ヘッダーの非公式表記、詳細欄、表示設定内の説明 | 表示内容と自動アクセシビリティ検査 |
| キーボード・スクリーンリーダー・狭い領域 | ラベル、HTML 参照一覧、フォーカス可能な詳細欄、コンテナクエリー | axe WCAG 2.1 AA、320/760/1440px、通常サイト・単独ページ |
| 応答性と失敗の認識 | Worker、結果キャッシュ、遅延結果の除外、エラーと再試行 | 連続ズーム12回：合計1.5秒未満・95%点100ms未満・最大250ms未満、Worker禁止時の失敗表示 |
| グラフ単独利用・Zennへ流用 | `embed.html` とデータ・Worker同梱 JS/CSS、固定版を保持する公開処理 | 別オリジン iframe から外部 JS/CSS を読み込み、選択・再配置・破棄を検証 |
| 安全な静的配信・GitHub Pages | テキスト描画、CSP、公開用ビルド、CI から Pages 配信 | 型チェック・単体・公開物のブラウザーテスト、公開権限をデプロイに限定 |

ローカルの検証対象は Chromium・WebKit・iPhone 相当の WebKit です。Firefox のプロジェクトも CI に含めていますが、現在の macOS 環境ではブラウザー自体が「Could not find profile folder」で起動できません。独立した人間による翻訳の査読、実機・実際のスクリーンリーダーでの全操作、CodePen 公開と Zenn の実記事プレビューは、この自動テストの範囲外です。
