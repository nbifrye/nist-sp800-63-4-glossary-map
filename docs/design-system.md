# グラフを中心にしたデザイン

## 情報の優先順位

1. グラフをトップ画面に表示し、未選択時は横幅をすべて使う。ページ切り替えや説明専用のセクションを置かない。
2. 日常的な操作は検索・表示範囲・ズームに限定する。用語検索は全見出しを対象にし、選択時だけ定義と根拠を開く。
3. 分類・配置・出典フィルターは「表示設定」にまとめる。計算条件、操作説明、原文、翻訳の確認情報は段階的に開示する。
4. 出典と非公式であることは短く表示する。長い注意書きは常設せず、関連する操作・情報の近くに置く。

## 共通スタイル

`src/explorer/explorer.css` の変数をサイト・埋め込みで共有する。

| 要素 | 基準 |
| --- | --- |
| 本文 / 補助文字 | `--ink` #173744 / `--muted` #516972 |
| アクセント | `--accent` #17665d。操作と選択の強調に使う |
| 背景 | `--paper` 白 / `--soft` #f1f6f5 |
| 境界 | `--line` #d6e1df。強い罫線を避け、領域を区切る |
| 角丸 | 操作部品 8px、浮いたパネル 12px |
| 余白 | 4px 単位。操作間 8–12px、パネル内 16–20px |
| 文字 | system-ui。本文 14–16px、補助 12px、見出し 18–20px |
| 操作領域 | 基本 40px、タッチでは最低 44px |
| フォーカス | 3px の青いアウトライン。色だけに頼らず輪郭で示す |

検索と設定はグラフの大きさを変えないフローティングパネル。定義は幅 360px のサイドパネルに表示する。760px 以下では詳細を画面下部の最大48%に置き、グラフを見ながら読めるようにする。閉じる操作はグラフへフォーカスを戻す。

検索は標準の検索入力とボタンで構成する。上下キー、Enter、Escape、Tab が使え、キャンバスを操作せずにすべての定義と参照へ到達できる。検索・設定は外側のクリックと Escape で閉じる。検索に一致しない状態と計算失敗は明示する。

用語・出典・方式などの共有可能な状態は URL に保持する。検索途中の文字列、パネルの開閉、ズームは一時的な UI 状態とする。以前の用語集 URL にある選択用語は、新しいグラフ画面でも開ける。

描画ライブラリの文字サイズ閾値を 8px に設定し、縮小時の小さな用語名を省略する。表示の切り替えは端末のピクセル比と描画スケールに従う。選択・ホバー中の用語名は縮尺にかかわらず表示する。小さすぎる文字の重なりと描画負荷を抑え、グラフの構造と現在の注目点を優先する。
