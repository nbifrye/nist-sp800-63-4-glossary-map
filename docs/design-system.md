# デザインの方針

## 情報の優先順位

1. トップ画面にグラフを表示し、用語を選んでいないときは横幅をすべて使う。ページの切り替えや、説明だけの領域は設けない。
2. よく使う操作として、検索、表示範囲の選択、拡大・縮小を配置する。検索はすべての見出しを対象とし、用語を選ぶと定義と参照の根拠を開く。
3. 分類方法、配置方法、出典の絞り込みは「表示設定」にまとめる。計算条件、操作説明、原文、翻訳の確認情報は、必要なときに開いて読めるようにする。
4. 出典と非公式であることを簡潔に示す。詳しい注意事項は、関連する操作や情報の近くに置く。

## 共通スタイル

`src/explorer/explorer.css` の変数を、通常サイトと埋め込み表示で共有する。

| 要素 | 基準 |
| --- | --- |
| 本文と補足の文字色 | 本文は `--ink` #173744、補足は `--muted` #516972 |
| 強調色 | `--accent` #17665d。操作できる箇所や選択状態を示す |
| 背景 | `--paper` は白、`--soft` は #f1f6f5 |
| 境界線 | `--line` #d6e1df。領域を区切るための控えめな色にする |
| 角丸 | ボタンなどの操作部品は 8px、グラフ上に重ねるパネルは 12px |
| 余白 | 4px 単位で指定する。操作部品の間は 8–12px、パネル内は 16–20px |
| 書体と文字サイズ | system-ui を使う。本文は 14–16px、補足は 12px、見出しは 18–20px |
| 操作領域 | 基本は 40px、タッチ操作では最低 44px を確保する |
| フォーカス | 3px の青い輪郭線で示す |

検索と設定のパネルはグラフ上に重ね、開いてもグラフの大きさを変えない。定義は、幅 360px の詳細欄に表示する。幅 760px 以下では、詳細欄を画面下部の最大48%の高さに収め、グラフを見ながら読めるようにする。詳細欄を閉じたら、グラフにフォーカスを戻す。

検索には標準の入力欄とボタンを使う。上下キー、Enter、Escape、Tab で操作できるようにし、すべての定義と参照を HTML の要素から読めるようにする。検索と設定は、外側のクリックまたは Escape キーで閉じる。検索に一致する用語がない場合や、計算に失敗した場合は、その状態を文章で伝える。

用語、出典、分類・配置方法など、共有できる状態は URL に保持する。入力途中の検索文字列、パネルの開閉、ズームは、そのページを開いている間だけ保持する。以前の用語集 URL で指定した用語も、グラフ画面で開けるようにする。

描画ライブラリの文字表示のしきい値を 8px に設定し、縮小時に小さくなりすぎる用語名を省略する。表示の切り替えには、端末のピクセル比と描画の縮尺を使う。選択中またはポインターを重ねている用語名は、縮尺にかかわらず表示する。これにより文字の重なりと描画の負荷を抑え、グラフの構造や選択中の用語を見やすくする。

参照を示す線には、背景になじむ淡い不透明色を使い、半透明の矢印が重なることによる描画の負荷を抑える。単独の参照は直線で、双方向の参照と自己参照は曲線で示す。
