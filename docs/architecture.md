# 構成

本サイトは、用語集の閲覧と、複数の分類・配置方式による参照グラフの比較を提供する静的サイトです。Issue #1 の本文とコメント 6072533111、6180078546 を要件とします。

## データの生成

`sources/` は原典 HTML と取得記録、`content/` は原文ハッシュで紐付けた訳文と確認履歴です。`npm run build:data` が保存済み原典を parse5 で読み、出典別の定義と参照根拠を生成します。通常のビルドはネットワークを使いません。

生成先の `src/generated/` は Git 管理外です。用語・出典別定義・参照箇所を正本とし、逆参照一覧とグラフの辺はそこから導出します。参照位置は Unicode コードポイント単位、0 始まり、終了位置を含まない範囲です。HTML は画面へ挿入せず、テキストと安全な DOM 操作で表示します。

原典 HTML のハッシュ、文書ごとの定義数、各原文と訳文の対応、参照先と原文位置を生成時に検証します。固定の用語数をアプリに埋め込みません。原文が変わった場合は対応する新しい訳文が必要です。

`npm run check:upstream` は最新原典との差分を JSON で報告し、保存済み原典を上書きしません。内容変更・取得や解析の失敗は非ゼロ終了です。

## 分類・配置

`src/analysis/` は DOM やサイトの URL に依存しない TypeScript の計算処理です。

- `clustering.ts`：無向・有向モジュラリティ、強連結成分、ラベル伝播、Louvain、スペクトル分類、2段階 map equation の貪欲結合。
- `layout.ts`：群別、強連結成分の階層、層状、力学、距離ストレス、スペクトル、放射状、円形。
- `graph.ts`：分析入力の正規化、一意の辺、隣接関係と弱連結成分。
- `spectral.ts` / `numerics.ts`：スペクトル分類・配置、対称 Jacobi 法、Cholesky 分解。
- `methods.ts`：手法の説明・論文・設定項目・既定値。
- `worker.ts`：画面処理を止めずに計算し、分類と配置を個別にキャッシュ。

分析入力は全出典の一意の方向付き参照です。自己参照は分析の重みに含めませんが、閲覧用のグラフと根拠には残します。無向方式は方向を除いてさらに重複を取り除きます。表示フィルターは分類・配置の入力を変えません。

分類は群の所属、配置は座標を返し、56組のノード配列は保存しません。群別配置のみ、選択中の分類に座標が依存します。それ以外は分類を切り替えても同じ配置になります。計算は要求時に実行し、乱数シードと訪問順を固定します。Node のテストとブラウザーの再計算は同じ実装を使います。

比較表は全用語・既定条件で計算した指標です。選択した設定での再計算や手動移動後の指標ではありません。Q と符号長 L は別の目的関数であり、数値を直接順位付けしません。方式の省略や限界は設定画面と比較パネルで説明します。

局所表示は、表示条件に合う直接の隣接用語を集めた誘導部分グラフです。選択用語を中央に置く補助配置を使い、分析で選んだ全体配置とは区別します。手動座標は分析結果とは別に、全体と用語ごとの局所表示でページ内に保持し、再読み込み時にはリセットします。

## UI と再利用

`mountExplorer(container, options)` が指定した領域にグラフ・設定・詳細欄を作ります。Cytoscape.js は描画と基本操作を担当し、分析計算は共有モジュールが担当します。各辺は原文の全出現箇所へ遡れます。HTML の用語選択、参照一覧、群の一覧からも情報に到達できます。

グラフはサイトの URL や `document.body` を変更しません。初期状態と状態変更の通知を受け渡すだけです。CSS と DOM 操作は表示先の内部に限定し、CSS コンテナクエリーで領域幅に応じてグラフと詳細欄を左右・上下に配置します。

`src/site/` が用語一覧・URL・通常サイトを担当します。`embed.html` は同じグラフ UI を単独表示します。`src/widget.ts` は原文データ、UI、計算と inline Worker をまとめた記事用 IIFE と CSS を出力します。Worker は Blob から生成するため、JS を外部オリジンから読み込む場合にも別 URL の Worker 取得を必要としません。ホストの CSP は Blob Worker を許可する必要があります。

通常サイトでは URL に用語・検索語・出典・参照種類・分類・配置・局所表示・計算条件を保持します。ズームと手動座標は一時状態です。`destroy()` は Worker、ResizeObserver と描画を破棄します。埋め込みの既定ではページスクロールを優先し、ボタンでグラフ操作へ切り替えます。

## 配信と検証

Vite が `dist/` に通常サイト・単独グラフ・記事用配布物を生成します。CI は Node.js の型チェック・単体テストと、`dist/` を配信した Playwright の操作・アクセシビリティ・描画性能の検証を行い、成功した成果物を GitHub Pages に公開します。

テストは小さな既知グラフの独立した計算で目的関数・定常流・符号長・距離ストレスを確認し、全56組の完全性と分類・配置の独立性を検証します。ブラウザーでは通常サイト・単独ページ・別オリジンの配布物を確認します。
